# Votaciones de Sala – Pantallazos

Galería de pantallazos de las votaciones de Sala de la Cámara de Diputadas y Diputados de Chile.
Se actualiza automáticamente durante las sesiones (lunes 17–19 h, martes y miércoles 10–14 h).

- `index.html`: la galería (sitio estático, desplegado en Vercel).
- `votaciones.json`: datos de cada votación.
- `AAAA-MM-DD_<ID>.jpg`: pantallazos.
